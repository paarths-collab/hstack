# Brand logos

Official brand marks for the platforms, integrations and coding agents listed on the site. Each brand's
logo is a trademark of its owner and is used here only to identify the product hstack connects to.

Sources, in order of preference:
- [Iconify `logos` set](https://github.com/gilbarbara/logos) (`@iconify-json/logos`, CC0): full-colour marks.
- [Simple Icons](https://simpleicons.org) (`simple-icons` 15.22.0, CC0): single-colour marks filled with the brand hex
  (google-chat, signal, replicate, hetzner, render, stripe, razorpay, brevo, calendly).
- The vendor's own site icon, where neither set has the brand: supermemory, e2b, postmark, sendbird, freshdesk
  (Freshworks mark), tally.
